# 거울 던전: 팬메이드 (데모)

림버스 컴퍼니 세계관을 바탕으로 한 비공식 팬메이드 로그라이크 덱빌딩 게임입니다.
슬레이 더 스파이어식 카드·분기 지도 + 다키스트 던전식 진형·정신력 관리를 섞었습니다.

- 비공식 팬 창작물이며 Project Moon과 관계없습니다.
- 비영리로 배포합니다. 후원·광고·유료 기능이 없습니다.
- 공식 일러스트·음악·로고를 사용하지 않았습니다.

## 플레이
`index.html` 하나로 동작합니다. GitHub Pages에서 Settings → Pages → Deploy from a branch → `main` / `(root)`로 켜면 링크로 바로 플레이할 수 있습니다.
